## Features

- Displays player levels directly in Meteor nametags
- Total Hypixel level support
- Meteor and Vanilla nametag themes
- Multiple level styles
- Adjustable text color and contrast
- Adjustable stroke and stroke color
- Adjustable background opacity
- Adjustable nametag scale
- Keeps Meteor nametag extras such as armor, health and items
- Cached background level lookups designed to minimize FPS impact

## Installation

1. Install **Fabric Loader** for Minecraft **26.1.2**.
2. Install **Meteor Client 26.1.2-41**.
3. Download [LevelHead 26.1.2.jar](./LevelHead%2026.1.2.jar).
4. Move the JAR into your Minecraft mods folder:
   ```
   .minecraft/mods
   ```
5. Start Minecraft using the Fabric profile.
6. Open Meteor Client and enable **LevelHead**.
7. Configure the level and render settings to your preference.

## Requirements

- Minecraft 26.1.2
- Fabric Loader
- Fabric API
- Meteor Client 26.1.2-41

## Notes

- Do not install multiple versions of LevelHead at the same time.
- When updating, remove the old LevelHead JAR from your mods folder first.
- Player level availability can depend on the data exposed by Hypixel and the available lookup providers.
