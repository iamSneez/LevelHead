LevelHead 26.1.2

Author: jupendeerus

LevelHead is a Meteor Client addon for Minecraft that displays player levels directly in nametags.

Installation
1. Install Fabric Loader for Minecraft 26.1.2.
2. Install Meteor Client 26.1.2-41.
3. Download "LevelHead 26.1.2.jar".
4. Place the JAR file in your Minecraft mods folder:
   .minecraft/mods
5. Start Minecraft with the Fabric profile.
6. Open Meteor Client.
7. Find LevelHead in the module list and enable it.
8. Configure the level display and Render settings to your preference.

Recommended
- Use the latest compatible version of Fabric API.
- Do not install multiple versions of LevelHead at the same time.
- If you update LevelHead, remove the older LevelHead JAR from the mods folder first.
